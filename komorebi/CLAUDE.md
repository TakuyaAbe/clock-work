# Komorebi Clock

ユーザーが画面で見て決めた値と、試して戻した案。変えるときは理由を添えて提案する。

- 時計の枝のぼかしは約 2.2 CSS px（`uRadN`）。1.35 px にしたら「趣がなくなった」。
- 針は時針の枝先でぴったり接する。中心を越えて反対側へ伸ばす案は、試して戻した。
- 描画は devicePixelRatio 2 まで（遅い GPU では 1.5 に下げる）、常に約 30fps。
- 毎分の雲は、光が約 30% まで落ちる深さ（`depth: 0.7`）。夜も同じ深さ。
- 夜の月明かりの下限は 0.35（`moon: 0.35 + 0.65 * lit * up`）。新月の夜も真っ暗にはしない。
- WebGL が使えない環境で、左下の時刻が出ないのは許容。
